# ایمپورت دستی دیتابیس حضوریار

فایل **hozoryar-install.sql** ساختار کامل دیتابیس را از migrationهای شماره 001 تا 011 می‌سازد و سابقه صحیح آن‌ها را در schema_migrations ثبت می‌کند. هیچ رمز، حساب پیش‌فرض، داده واقعی یا فایل دیتابیس محلی در آن نیست.

## ایمپورت در phpMyAdmin

۱. در کنترل‌پنل هاست، یک دیتابیس MySQL/MariaDB **جدید و خالی** و یک کاربر اختصاصی بسازید و دسترسی کاربر را به همان دیتابیس بدهید.
۲. در phpMyAdmin، همان دیتابیس را انتخاب کنید و از بخش Import فایل `hozoryar-install.sql` را با UTF-8 وارد کنید. ایمپورت باید با اولین خطا متوقف شود.
۳. این فایل را فقط یک بار روی دیتابیس خالی وارد کنید؛ همراه آن، فایل‌های 001 تا 011 را دوباره ایمپورت نکنید. برای دیتابیس موجود از ابزار migration و بکاپ استفاده کنید، نه این فایل نصب اولیه.
۴. پس از موفقیت، جدول schema_migrations باید ۱۱ ردیف با status برابر applied داشته باشد.

## محل واردکردن اطلاعات دیتابیس روی هاست فعلی

با چیدمان اکشن فعلی، فایل ثابت اتصال را در این مسیر بسازید:

`public_html/_private/hozoryar/php/config.php`

حساب FTP شما مستقیماً داخل public_html باز می‌شود؛ بنابراین مسیر قابل مشاهده در FTP این است:

`/_private/hozoryar/php/config.php`

اگر پوشه php در این مسیر وجود ندارد، آن را بسازید. اطلاعات را **در این فایل ثابت** بنویسید، نه در پوشه releases یا فایل‌های برنامه. محتوای فایل:

```php
<?php
return [
    'db_host' => 'localhost',
    'db_port' => '3306',
    'db_name' => 'YOUR_DATABASE_NAME',
    'db_user' => 'YOUR_DATABASE_USER',
    'db_pass' => 'YOUR_DATABASE_PASSWORD',
];
```

مقادیر db_name، db_user و db_pass را با اطلاعات واقعی کنترل‌پنل جایگزین کنید. نام کامل دیتابیس و کاربر معمولاً پیشوند حساب هاست دارد؛ مقدار دقیق را از کنترل‌پنل بردارید. اگر میزبان دیتابیس آدرس دیگری ارائه داده است، db_host و پورت را مطابق همان اطلاعات تنظیم کنید.

فایل `_private/.htaccess` که اکشن ساخته است باید باقی بماند و دسترسی وب به این پوشه مسدود باشد. config واقعی را در GitHub یا چت قرار ندهید. اکشن‌های بعدی آن را بازنویسی نمی‌کنند. در اجرای محلی پروژه، مسیر متناظر `php/config.php` است و نمونه آن در `php/config.example.php` قرار دارد.

## حساب اولیه و ادامه راه‌اندازی

ایمپورت SQL حساب مدیر یا شرکت نمی‌سازد. برای ساخت شرکت و مالک، ابزار `php/cli/bootstrap-company.php` را از Terminal هاست طبق راهنمای `docs/SHARED_HOST_SETUP.md` اجرا کنید؛ HOZORYAR_CONFIG باید مسیر مطلق فایل ثابت بالا باشد. رمز مدیر را در SQL عمومی قرار ندهید.

## نگهداری فایل نصب

پس از افزودن migration جدید، از ریشه مخزن اجرا کنید:

```sh
php php/cli/build-install-sql.php
php php/cli/build-install-sql.php --check
```

این پوشه از اجرای خودکار `php/db/*.sql` جداست؛ نصب یکپارچه دوباره به عنوان migration مستقل اجرا نمی‌شود. checksumها نسبت به تفاوت پایان خط ویندوز و لینوکس پایدار هستند؛ checksumهای قدیمی همان محیط نیز پذیرفته می‌شوند.
