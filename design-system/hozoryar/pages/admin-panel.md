# پنل مدیریت حضوریار

این صفحه برای بازطراحی درخواستی کاربر بر پیشنهادهای عمومی MASTER اولویت دارد.

- مرجع مشاهده‌شده: داشبورد داخلی فینتو در مرورگر؛ زمینه تیره، منوی جانبی، کارت‌های وضعیت رنگی، راه‌اندازی سریع و جدول‌های مجزا.
- لوگو، نام، متن و رنگ اصلی متعلق به حضوریار است: بنفش #6D28D9؛ از دارایی یا کد فینتو استفاده نمی‌شود.
- زمینه #101119، سطح #191A23، مرز #313240، متن اصلی #F0EDF7، متن ثانویه #AAA9BA.
- فونت فارسی Vazirmatn با fallback تاهوما؛ جهت RTL و ارتفاع خط ۱٫۷.
- منوی سمت راست ۲۴۰ پیکسل در دسکتاپ؛ در عرض کم منوی افقی پیمایش‌پذیر با خروج قابل دسترسی.
- چهار کارت: کل پرسنل، حضور فعال، فاقد حضور فعال، تعداد نشست‌های ورود در بازه. «فاقد حضور فعال» الزاماً غیبت کاری نیست و باید همین عنوان را حفظ کند.
- فهرست‌ها فقط از داده API شرکت جاری ساخته شوند؛ آمار مرخصی یا مأموریت بدون منبع معتبر نشان داده نشود.
- کنترل حداقل ۴۴ پیکسل، focus مشخص، برچسب فرم، نماد SVG، reduced-motion و پیمایش مستقل جدول الزامی است.
- CSS مشترک PHP و نسخه مرجع Node است؛ ورودی اصلی PHP/MySQL می‌ماند.
- انتخاب روشن/تیره/سیستم با ذخیرهٔ ترجیح؛ پوستهٔ روشن سطح سفید، پس‌زمینه خاکستری بسیار روشن و همان بنفش سازمانی دارد. گزارش‌ها و فرم‌ها باید در هر دو حالت خوانا باشند.
- منوی گزارش‌ها گروه‌بندی شود؛ حضور شخصی و GPS فقط در اپ اندروید است. پنل وب صفحه معرفی اپ دارد و دکمه ثبت تردد ندارد.
- مرکز گزارش، ورودی تاریخ شمسی/میلادی، وضعیت بارگذاری و خطا و خروجی‌های قابل بررسی را در یک الگوی مشترک عرضه می‌کند.
