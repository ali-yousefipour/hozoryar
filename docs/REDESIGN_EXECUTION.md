# بازطراحی حضوریار — ۲۰۲۶/۱۱/۲۴

## وضعیت مبنا
شاخه codex/hozoryar-product-redesign با حفظ تمام تغییرات ثبت‌نشده قبلی ساخته شد. مسیر اجرایی PHP/MySQL است. متن‌های قدیمی که پروژه را Node-only معرفی می‌کنند یا تکمیل تردد ناقص را غایب می‌دانند، وضعیت تاریخی‌اند؛ کد فعلی CorrectionsApi حالت complete دارد.

آزمون اولیه: ۷۵ آزمون، ۵۷ موفق، ۱۸ ردشده از اجرا به علت نبود PHP در PATH و نبود پیکربندی آزمون. این نتیجه پاس کامل PHP نیست.

## شکاف‌ها و ترتیب اجرا
۱. سایت معرفی مستقل و ورود مشخص؛ بدون قیمت یا آمار ساختگی.
۲. راه‌اندازی مبتنی بر داده شرکت: محل کار، شیفت، پرسنل، تخصیص و اولین تردد.
۳. ثبت درخواست کارکنان در اندروید؛ فرم موجود فقط فهرست را نشان می‌داد.
۴. حفاظت درخواست جدید در دوره بایگانی‌شده و آزمون مسیر کامل PHP با دو شرکت.
۵. یکپارچه‌سازی طراحی، بررسی اندازه‌ها، بسته هاست و مستند تحویل.

## حدود انتشار
داده عملیاتی مهاجرت نمی‌شود. آزمون دستگاه حقیقی، APK امضاشده، هاست واقعی، پیامک هزینه‌زا و تأیید مالی سازمانی به شواهد بیرونی نیاز دارند. هیچ‌کدام با موفقیت آزمون محلی جایگزین نمی‌شوند.

فایل‌های branding/hozoryar-logo.png و mobile/assets/logo.png هم‌هش و دارای خطای decode هستند؛ نسخه ثبت‌شده Git نیز همان خطا را دارد. اصل فایل‌ها حفظ شده و در صفحات وب/هدر اپ از نام فارسی محصول استفاده می‌شود. آیکن و splash بسته اندروید هنوز به فایل اصلی اشاره دارند؛ پیش از APK نهایی، نسخه سالم لوگوی تأییدشده لازم است. قلم Vazirmatn از دارایی محلی خطیار با مجوز OFL رسمی همراه شد؛ قلم به سرویس بیرونی وابسته نیست.

## جهت طراحی
وب عملیاتی: زمینه خنثی روشن برای کار روزانه اداری، تم تیره برای انتخاب کاربر، بنفش فقط برای هویت و اقدام، آمار با رنگ وضعیت در آیکن، جدول دارای پیمایش مستقل. سایت معرفی: متن واقعی و یک ناحیه بنفش برای توضیح مسیر؛ بدون نمایش داده جعلی. حفظ برند و تصمیم‌گیری معمول بر اساس پرامپت صریح کاربر انجام شد.

## شواهد تحویل محلی
- مجموعه اصلی: ۷۸ نتیجه موفق، صفر خطا و صفر skip با PHP قابل‌حمل و دیتابیس اختصاصی hozoryar_test_reports.
- مسیر HTTP افزوده: سایت و ورود، نقش‌ها، دو شرکت، محل کار، شیفت و تخصیص، تردد و replay، گزارش مدیر، ثبت/تصمیم درخواست، جلوگیری از ثبت در بایگانی، ظرفیت پرسنل و کامل‌شدن تخصیص فقط برای کارکنان فعال.
- tests/khatyar-source-parity.php در برابر مخزن محلی خطیار: ۱۲ مقایسه مدت شیفت و شب‌کاری برابر؛ آزمون همه قواعد مالی نیست.
- PHP lint و بررسی نحو فایل‌های JS بدون خطا. Android Metro export با ۵۹۳ ماژول موفق شد؛ خروجی bundle است، نه APK امضاشده.
- محیط PHP 8.3، افزونه‌ها، اتصال MySQL، AES-256 ZIP و checksum یازده migration معتبر بودند. اجرای دوباره migration بدون اجرای مجدد DDL انجام شد.
- بسته data/hozoryar-shared-host.zip از نظر سلامت ZIP، فایل‌های لازم و نبود config واقعی، data و node_modules بررسی شد.
- مرورگر: ورود واقعی شرکت ساختگی، ساخت و تخصیص شیفت، تغییر وضعیت راه‌اندازی، گزارش تردد با ورودی شمسی، منوی موبایل و تم‌ها بررسی شدند. عرض‌های ۳۶۰، ۷۶۸، ۱۳۶۶ و ۱۹۲۰ برای سایت و داشبورد بررسی شدند؛ تصاویر در .impeccable/review قرار دارند. نمای تبلت پس از اصلاح تداخل CSS دوباره ثبت شد.

## بازگشت و استقرار
بسته جدید را ابتدا کنار نسخه فعلی در staging باز کنید. کد خصوصی خارج از public_html و config واقعی خارج از Git بماند. قبل از انتشار از MySQL نسخه رمزگذاری‌شده بگیرید و صحت آن را با ابزار docs/MYSQL_BACKUP.md بررسی کنید. تغییر مسیر وب و config باید پس از آزمون همان هاست انجام شود؛ برای بازگشت، ورودی وب و config قبلی را برگردانید. در این مرحله هیچ migration جدیدی به schema اضافه نشده است؛ ابزار موجود یازده migration قبلی را کنترل می‌کند. بازیابی داده در دیتابیس جدا و خالی انجام شود، بدون بازنویسی منبع فعلی. داده SQLite موجود خودکار به MySQL منتقل نشده است.

## موارد باز
نسخه سالم لوگوی تأییدشده برای آیکن/splash اندروید، APK امضاشده و آزمون دستگاه/باتری، استقرار و rollback روی هاست واقعی، مهاجرت واقعی SQLite در صورت نیاز، پیامک/نقشه با کلید واقعی و تأیید سیاست مالی سازمانی هنوز به کار و شواهد جداگانه نیاز دارند. این تحویل تکمیل محلی بخش‌های مشخص‌شده است و به معنی آماده‌بودن کامل محصول برای بهره‌برداری نهایی نیست.

## بازبینی طراحی
بازبین مستقل ابتدا دو تصویر با اندازه/برش نامعتبر را رد کرد. تصویر بلند حذف و به تصاویر مستقل بخش‌ها با عرض ثبت‌شده جایگزین شد. تصاویر تبلت دوباره ثبت و برابری عرض پیمایش منو با عرض قابل نمایش تأیید شد. بازبین در دور بعد فقط حذف سه عنوان ریز تکراری بالای مراحل سایت را خواست؛ اصلاح انجام شد و بازبین رفع آن را تأیید کرد؛ نتیجه ship فقط در دامنه همان فهرست اصلاح است. بررسی ظاهر اندروید به کد محدود است و تأیید دیداری دستگاه اعلام نشده است.

مستند طراحی نهایی در DESIGN.md و توکن‌های قابل خواندن ابزار در .impeccable/design.json ثبت شده‌اند. این فایل‌ها تفاوت واقعی سایت، پنل و تم‌ها را حفظ می‌کنند و ادعای یکپارچه‌شدن همه CSSهای قدیمی یا تأیید دیداری اندروید ندارند.
