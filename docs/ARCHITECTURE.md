# معماری حضوریار — نسخه پایه 0.1

## چندشرکتی (Multi-tenant)

در نسخه پایه، هر شرکت یک `companies.id` مجزا دارد. `company_id` برای پرسنل، شیفت، تخصیص، ورود و خروج، موقعیت زنده، نشست‌ها، تنظیمات و لاگ عملیات ثبت شده است. کاربر با `company.slug` وارد می‌شود و هویت شرکت از توکن نشست سرور استخراج می‌شود؛ API نباید `company_id` ارسالی کلاینت را مبنای دسترسی قرار دهد.

- مدیر هر شرکت تنها می‌تواند داده همان شرکت را مشاهده کند.
- کلید سرویس پیامک و نقشه نشان برای هر شرکت جدا ذخیره می‌شود و در پاسخ تنظیمات ارسال نمی‌شود.
- ورود و خروج با شناسه کاربر تأییدشده انجام می‌شود؛ ثبت/خواندن تردد سایر کاربران تنها با دسترسی مدیریتی همان شرکت است.
- موقعیت زنده به کارمند شرکت و حضور باز محدود است.
- توکن نشست در پایگاه داده فقط به صورت هش ذخیره می‌شود.
- تنظیمات قابلیت‌ها در سطح شرکت اعمال می‌شود؛ دسترسی‌ها سمت سرور بررسی می‌شوند.

### محدودیت‌های نسخه پایه

این نسخه آغاز توسعه است، نه نسخه آماده بهره‌برداری سازمانی. موارد زیر هنوز به فاز بعد نیاز دارند:

- پیاده‌سازی کامل موتور کارکرد `ShiftCalc`، تقویم جلالی رسمی، درخواست‌ها، مأموریت، مرخصی، گزارش ماهانه، حقوق و نهایی‌سازی.
- GPS پس‌زمینه و اعلان‌های اندروید با مجوز روشن و امکان توقف نظارت، نسخه بومی APK و انتشار.
- صحت‌سنجی تصویری مبتنی بر رضایت و سیاست اعلام‌شده به کاربر؛ از تصویربرداری نامحسوس در این پایه استفاده نشده است.
- تست عملی کلیدهای Neshan و Kavenegar، مدیریت صف، retry و محدودسازی تعداد پیامک.
- SSL/TLS، reverse proxy، بکاپ، rate limiting، مدیریت امن اسرار و سیاست نگهداری داده پیش از انتشار.
- ایزوله‌سازی سخت‌تر در پایگاه داده production از طریق MySQL/PostgreSQL و آزمون‌های نفوذ cross-tenant.

## نقشه و پیامک

نقشه زنده در پنل از OSM یا کاشی‌های Neshan با پراکسی مجازشده استفاده می‌کند. کلید نشان در سمت سرور نگهداری می‌شود. اتصال به Neshan تنها پس از ثبت کلید معتبر در تنظیمات هر شرکت فعال می‌شود. کاوه‌نگار به‌عنوان آداپتور اولیه پیامک پیاده‌سازی شده، اما بدون کلید و روشن بودن قابلیت در شرکت، ارسال ممکن نیست.

## راه‌اندازی توسعه

نیازمند Node.js 22.13 یا جدیدتر است و وابستگی npm خارجی ندارد.

```bash
npm run bootstrap -- acme "شرکت نمونه" admin "replace-with-strong-password" "مدیر سامانه"
npm start
```

سپس `http://127.0.0.1:3000` را باز کنید. برای کار با GPS مرورگر، دامنه امن HTTPS لازم است (localhost استثنا است).

```bash
npm test
```

## منابع قابل استفاده از خطیار

در فازهای بعدی منطق محاسبه کارکرد و تقویم از `php/lib/ShiftCalc.php` و `php/lib/IranCalendar.php`، سیاست‌های حضور از `docs/WEB_PERSONAL_ATTENDANCE.md` و `docs/ATTENDANCE_WORK_CALCULATION.md` و الگوهای نظارت از `docs/internet-work-deduction.md` با بازنویسی مستقل و تست چندشرکتی منتقل می‌شوند. کد خطیار مستقیماً به این پروژه کپی نشده است.
